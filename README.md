# Conditional Probability in Smart Irrigation

## Group 6 – Statistical Methods and Probability IA-1

### Topic

Conditional Probability in Smart Irrigation

### Case Study

AI-Based Smart Irrigation Advisory for Sugarcane

## Project Overview

This project investigates how conditional probability can be used
to support irrigation decisions based on soil moisture and rainfall
conditions.

## Statistical Concepts

- Conditional Probability
- Joint Frequency Distribution
- Marginal Frequency Distribution
- Independent Events / Random Variables
- Probability-based Decision Making

## Engineering Application

The statistical analysis will be used to support an irrigation
decision based on observed soil moisture and rainfall conditions.

## Project Flow

Data Input
→ Statistical Analysis
→ Probability Calculation
→ Result
→ Irrigation Decision

## Repository Structure

- `data/` – Dataset used for the investigation
- `src/` – Python source code
- `notebooks/` – Jupyter notebooks and analysis
- `results/` – Tables, graphs and outputs
- `docs/` – Investigation sheet and references
